## ▶️ Run Locally

```text
1. Download or clone the portfolio project.
2. Keep index.html and style.css in the same directory.
3. Open index.html in a modern web browser.
```

Or use a local development server (requires Python):

```bash
python -m http.server 8000
```

Then open **http://localhost:8000**.

> ⚠️ Run the command from the folder containing `index.html`. The page references `style.css`, so that file must be present for the intended styling. The theme toggle needs JavaScript and browser storage; if storage is blocked, persistence may not work.
